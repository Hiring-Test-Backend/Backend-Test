# VeriFi AI — savings task

API only. Auth works. Goals live in memory in `server/src/store.ts`. No database and no `.env`.

Complete the two `TODO`s in `server/src/routes/savings.routes.ts`, then push your branch. Start with [ASSIGNMENT.md](./ASSIGNMENT.md).

## Setup

```bash
git checkout main
git pull
git checkout -b solution/savings-goals
npm install
npm run dev
```

The API is at http://localhost:3001.

## Layout

```
ASSIGNMENT.md                       Brief
server/src/store.ts                 in-memory users + goals
server/src/routes/savings.routes.ts two TODOs
```
